Architecture & Scalability Guidance
Local Background Worker Queue

CertiFlow operates an isolated threaded worker queue with atomic database session commits per recipient. Long-running PDF rendering runs outside open transactions to eliminate database lock contention.

When to Deploy PostgreSQL & Celery/Redis

For production deployments generating 50,000+ certificates concurrently across multiple server instances, Celery with a Redis broker and PostgreSQL is recommended to achieve distributed multi-node task consumption and connection pooling without SQLite write serialization locks.
